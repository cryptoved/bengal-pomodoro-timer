# Bengal Pomodoro Timer: Focus & Fitness Breaks

Bengal Pomodoro Timer is a playful Chrome extension that helps users stay focused, take healthy movement breaks, and keep lightweight local notes during the workday.

An animated Bengal cat reminds you when it is time to move, stretch, reset, and return to your next focus sprint with more energy.

## Features

- Customizable focus sprint and break durations
- Animated Bengal cat break overlay
- Multiple movement exercises
- Custom exercise names and descriptions
- Work, break, and rest comments
- Checklist-style tasks inside comments
- Daily timeline for sprints, breaks, pauses, and rest
- Statistics for today, yesterday, a selected day, or a custom period
- Mini sprint widget for quick notes
- Optional sound reminders and notifications
- Multilingual interface
- Local-first storage in Chrome

## Privacy-first design

Bengal Pomodoro Timer does not use analytics, advertising trackers, remote code, or external servers for user data.

The extension stores settings, timer state, comments, checklist items, custom exercises, and local statistics in Chrome storage on the user's device.

## Permissions

The extension uses Chrome permissions only to provide its timer, overlay, widget, sound, notification, and local storage features.

- `storage`: saves settings, notes, tasks, exercises, and local statistics.
- `alarms`: keeps timer events running reliably in the background.
- `tabs`: coordinates overlays and widgets across browser tabs.
- `scripting`: displays the break overlay and mini widget on webpages.
- `offscreen`: plays reminder sounds when needed.
- `notifications`: shows fallback reminders when the overlay cannot be displayed.
- `<all_urls>` host access: allows the timer overlay and mini widget to work across websites by default.

## Installation

The recommended installation method is through the Chrome Web Store.

For local testing, the extension can be loaded as an unpacked Chrome extension from the project folder.
