Bengal Pomodoro Timer

Privacy Policy

Last updated: May 18, 2026

Bengal Pomodoro Timer is designed as a local-first Chrome extension. It does not sell user data, does not use analytics trackers, and does not send user notes or productivity statistics to external servers.

Overview

Bengal Pomodoro Timer helps users manage focused work sessions, movement breaks, lightweight notes, checklist items, custom exercises, and local productivity statistics inside Chrome.

Data Stored by the Extension

The extension may store the following information in Chrome storage on the user's device:

  • Timer settings, including work and break durations
  • Current timer state, including sprint, break, pause, and rest status
  • Selected exercises and custom exercise names or descriptions
  • User-created comments and checklist items
  • Local statistics, including sprint, break, pause, rest, and exercise history
  • Language, sound, widget, and display preferences

Data Collection and Transfer

Bengal Pomodoro Timer does not sell, share, or transfer user data to third parties. The extension does not use analytics, advertising trackers, remote code, or external servers for user data.

Website Access

The extension requests access to websites so it can display the timer widget, break overlay, reminders, and Bengal cat animation on pages where the user is working.

The extension does not record browsing history, collect visited URLs, read website content for tracking purposes, or send browsing data anywhere.

User Notes and Checklist Items

Notes, comments, checklist items, and custom exercises entered by the user are stored locally in Chrome storage and are used only to provide the extension's focus, break, note-taking, checklist, and statistics features.

Health and Activity Information

The extension may store local information about movement breaks and selected exercises, such as which exercise was shown and whether a break was marked as completed. This information is used only for local statistics inside the extension.

Remote Code

Bengal Pomodoro Timer does not use remote JavaScript or WebAssembly code. All extension code is included in the extension package.

Chrome API Use

Information received from Chrome APIs is used only to provide the extension's single purpose: focus timing, movement break reminders, local notes, and local statistics. The extension's use of Chrome API data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Data Retention and Control

Users can clear stored history from the extension's statistics screen. Users can also remove the extension from Chrome to delete extension data associated with the browser profile.
